# MicroQuest

> Um RPG de turnos simplificado, desenvolvido na Godot Engine.

## Sobre o projeto

Este projeto é um jogo de RPG de turnos que ainda está em desenvolvimento. A proposta é criar uma experiência simples e acessível, com combates estratégicos, exploração e evolução de personagens.

Durante as batalhas, o jogador deverá escolher suas ações a cada turno, podendo atacar, defender-se, utilizar habilidades ou consumir itens. O objetivo é oferecer um sistema fácil de aprender, mas que permita diferentes estratégias durante os confrontos.

## Estado atual

🚧 **Projeto em desenvolvimento.**

O jogo ainda está em uma fase inicial, portanto suas mecânicas, interface, história e elementos visuais poderão sofrer alterações ao longo do desenvolvimento.

## Funcionalidades planejadas

- Sistema de combate por turnos;
- Ações de ataque, defesa, habilidades e uso de itens;
- Diferentes personagens e inimigos;
- Sistema de vida, dano e atributos;
- Evolução dos personagens;
- Inventário de itens;
- Exploração de mapas;
- Diálogos e pequenas missões;
- Interface simples e intuitiva;
- Sistema de vitória e derrota;
- Salvamento e carregamento do progresso.

## Tecnologias utilizadas

- [Godot Engine](https://godotengine.org/)
- GDScript
- Git e GitHub para versionamento

## Como executar o projeto

1. Instale a [Godot Engine](https://godotengine.org/download/).
2. Clone este repositório:

   ```bash
   git clone https://github.com/Kaue-Cardoso/MicroQuest
   ```

3. Abra a Godot Engine.
4. Selecione **Importar** e localize o arquivo `project.godot`.
5. Abra o projeto e pressione `F6` para executar a cena atual ou `F5` para executar o jogo.

## Objetivo do projeto

O principal objetivo é estudar e aplicar conceitos de desenvolvimento de jogos na Godot Engine, incluindo:

- Organização de cenas e nós;
- Programação com GDScript;
- Máquinas de estado e controle de turnos;
- Criação de interfaces;
- Gerenciamento de personagens, inimigos e atributos;
- Desenvolvimento e balanceamento de mecânicas de RPG.
